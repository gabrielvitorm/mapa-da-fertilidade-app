# Quiz v2: capítulos, progresso e retomada - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar o fluxo `/quiz` em uma jornada por capítulos com progresso segmentado, retomada local, integração com `/captura` e uma etapa de cálculo mais cênica, sem alterar schema Prisma, seed, motor de score ou o contrato de `POST /api/assessments`.

**Architecture:** A implementação é dividida em duas fases. A primeira cria a base derivada de capítulos, persistência local e preview dedicado; a segunda adiciona máquina de estados, intros de pilar, animações e a tela de cálculo com retry. O fluxo continua centralizado em `QuizFlow`, mas a lógica derivada sai para helpers puros e componentes pequenos.

**Tech Stack:** Next.js App Router, React 19, TypeScript, `motion`, `lucide-react`, `localStorage`/`sessionStorage`, Prisma já existente, ESLint e `tsx` para testes leves.

## Global Constraints

- Não alterar perguntas, respostas, ordem ou pontuação.
- Não alterar schema Prisma.
- Não alterar `POST /api/assessments`.
- Não introduzir dependência nova.
- `motion` já está instalado e deve ser reutilizado.
- Nenhum `41`, `42` ou `13` hardcoded pode continuar sendo fonte de verdade para o fluxo.
- `leadData` continua em `sessionStorage`.
- O preview do quiz deve funcionar sem banco.
